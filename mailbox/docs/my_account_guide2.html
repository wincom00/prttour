연결 완료
  1. 이메일 · 표시명 입력
  2. 메일 제공자 Gmail → 인증 방식 OAuth2 · OAuth 제공자 Google
  3. 저장 → 목록에서 ✎ 수정 → OAuth 계정 연결
  4. [연결됨] 확인 후 연결 테스트
00:00

따라 하기 요약 — prttour.com 계정

  1. 왼쪽 메뉴 내 계정 → 오른쪽 내 계정 추가 폼
  2. 이메일·표시명 입력 (표시명은 받는 사람에게 보이는 이름)
  3. 메일 제공자는 Gmail — prttour.com은 Google Workspace라 IMAP/SMTP가 Gmail 주소로 자동 입력됩니다
  4. 인증 방식을 OAuth2로 바꿉니다. 앱 비밀번호 칸이 사라지고 OAuth 제공자 칸이 나타납니다 → Google
  5. 사용 체크 후 저장. 신규 등록은 저장해야 연결 버튼이 생깁니다
  6. 목록에서 방금 만든 계정의 ✎를 눌러 수정 폼을 열고 OAuth 계정 연결 클릭
  7. Google 인증 창에서 계정 선택 → 허용 → 돌아오면 배지가 연결됨으로 바뀝니다
  8. 마지막으로 버튼을 눌러 연결 테스트
prttour.com 주소는 앱 비밀번호를 쓰지 않습니다. 회사 Google Workspace 계정이라 앱 비밀번호 발급이 막혀 있고, 인증 방식을 앱 비밀번호로 두면 연결 테스트가 실패합니다. 반드시 OAuth2 + Google로 등록하세요.
앱 비밀번호 방식은 개인 Gmail·Outlook 계정을 추가할 때만 사용합니다. 그때는 2단계 인증을 켜고 발급한 16자리를 띄어쓰기 없이 붙여넣습니다.
연결이 끊기면 다시 ✎ 수정 → OAuth 계정 연결만 하면 됩니다. 계정을 지웠다 다시 만들 필요는 없습니다.
내 계정은 본인만 관리합니다. 등록·수정·삭제 모두 본인 소유 계정에만 적용되고, 공통 이메일은 관리자가 계정 관리에서 지정합니다.

화면은 실제 메일 › 내 계정 페이지를 재현한 데모입니다. 입력값은 예시이며 실제로 저장되지 않습니다. Google 인증 창 구간은 재현하지 않고 안내 카드로 대신했습니다.
